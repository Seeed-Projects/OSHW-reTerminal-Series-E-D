# reTerminal E1003 电子相框 · 使用说明

10.3 英寸 16 级灰度墨水屏，从 SD 卡读照片自动轮播；不拔卡也能用 Wi-Fi 传图。

---

## 1. 日常使用

| 操作 | 方法 | 提示音 |
|---|---|---|
| 自动轮播 | 开机即开始，每张停留 **30 秒** | — |
| 下一页 | 按 **左键**（KEY2） | 高音 2000 Hz |
| 上一页 | 按 **中键**（KEY1） | 低音 1200 Hz |
| 进入传图模式 | **长按右键**（KEY0）约 2 秒 | 两声上行音 |
| 退出传图模式 | 传图模式下同样长按右键约 2 秒 | 两声下行音，然后重启 |

- 手动翻页后，30 秒自动计时重新开始。
- 首尾相连：最后一张按"下一页"回到第一张，反之亦然。
- 换一张图需要解码 + 抖动 + 整屏刷新，约 **4–5 秒**；这期间按键不响应，属正常。
- 按键在按下瞬间发声，所以按下就"有回应"，不用等屏幕刷完。

## 2. 传照片（Wi-Fi，不用拔卡）

1. 长按 **右键** 2 秒 → 屏幕显示热点名、密码和网址。
2. 手机或电脑连上热点：

   | 项目 | 值 |
   |---|---|
   | 热点名 SSID | `E1003-Photo` |
   | 密码 | `e1003photo` |
   | 网页地址 | `http://192.168.4.1` |

3. 浏览器打开上面的地址，把照片拖进去（手机上直接点选框从相册选，或调起相机）。
   页面默认勾选 **「按屏幕比例裁剪」**：按屏幕比例居中裁剪；
   想保留完整画面就取消勾选（留白会更多）。固件不会放大图片，四周仍会留白。
4. 传完长按右键 2 秒退出，板子重启并开始轮播新照片。

**尺寸会自动处理**：手机拍的 4000×3000 原图，网页会先在手机上缩到板子允许的
1170×876 再上传（约 150–300 KB 一张），不需要改手机相机设置。
如果照片已经手动调好尺寸，勾选「上传原图」可跳过缩放，保留原始质量。

> 板子只支持 **JPEG / PNG / BMP**。iPhone 从相册选图通常会自动转 JPEG；
> 如果页面提示"无法解码（HEIC）"，请先在相册里导出成 JPEG。

传图模式下 **10 分钟无操作会自动退出**并回到轮播，不用担心忘了关。

## 3. 直接拷到 SD 卡（备选）

1. 卡格式化为 **FAT32**（容量 ≤ 64 GB，实测 14.9 GB 卡正常）。
2. 照片放进卡里的 **`/img`** 文件夹；文件按**文件名排序**播放。
3. 建议提前在电脑上批量缩图：

   ```powershell
   python tools\prepare_photos.py D:\照片 D:\out
   ```

   默认缩到 1100×825，输出按 `001_xxx.jpg` 编号，拷进 `/img` 即可。

## 4. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 某张照片一闪而过或被跳过 | 图片太大，PSRAM 装不下。用网页传（会自动缩放），或先缩到 1100×825 |
| 屏幕一直空白 | 首次上电冷启动的完整刷新可能较慢；插着 USB 按一下 RESET |
| 拔插卡后没反应 | 运行时拔卡不会重新挂载，插回后按 RESET |
| 卡里一张图都没有 | 开机会**自动进入传图模式**，直接传就行 |
| 手机连上热点但打不开网页 | 确认地址是 `http://192.168.4.1`（http，不是 https）；忘记网络后重连 |
| 网页传图提示"太大" | 没开自动缩放？勾掉「上传原图」再试 |
| 按键没反应 | 每次刷新约 4–5 秒，期间按键被忽略；等屏幕刷完再按 |
| 提示音太吵 | 代码里 `BUZZER_FEEDBACK = false` 可整体关闭 |

## 5. 可调参数（`E1003_SDcard_Slideshow.ino` 顶部）

| 参数 | 默认 | 说明 |
|---|---|---|
| `IMAGE_DIR` | `/img` | 扫描的目录，不存在则用卡根目录 |
| `SLIDE_INTERVAL_MS` | `30000` | 每张停留时间，建议 ≥15000 |
| `DITHER_METHOD` | `DITHER_FS` | 画质最均衡；`DITHER_BAYER8` 支持更大的图但颗粒感更强 |
| `DITHER_GAMMA` | `1.0` | >1 变暗，<1 变亮 |
| `DISPLAY_FIT` | `FIT_CONTAIN` | 超出面板时缩小，不放大 |
| `AP_SSID` / `AP_PASSWORD` | `E1003-Photo` / `e1003photo` | 热点名和密码 |
| `UPLOAD_HOLD_MS` | `2000` | 长按多久进入传图模式 |
| `BUZZER_FEEDBACK` | `true` | 按键提示音开关 |

改完之后重新编译烧录：

```powershell
arduino-cli compile --fqbn "esp32:esp32:XIAO_ESP32S3:FlashSize=8M,PartitionScheme=default_8MB,PSRAM=opi" .
arduino-cli upload  -p COMx --fqbn "esp32:esp32:XIAO_ESP32S3:FlashSize=8M,PartitionScheme=default_8MB,PSRAM=opi" .
```

调试日志走 USB-UART，**115200**（GPIO43 TX、GPIO44 RX）。

## 6. 文件清单

| 文件 | 作用 |
|---|---|
| `E1003_SDcard_Slideshow.ino` | 主程序 + 全部配置 |
| `upload_mode.h / .cpp` | Wi-Fi 传图模式（热点 + 网页） |
| `dither.*` / `image_loader.*` / `pngle.*` / `miniz.*` | 解码与抖动（来自 Seeed 官方示例） |
| `driver.h` | 选中 E1003 屏（1872×1404，Gray16） |
| `README.md` | 技术细节与已知行为 |
| `tools/prepare_photos.py` | 电脑端批量缩图 |

> 说明：本机**不能**做成 USB 读卡器——USB-C 口接的是 CH340K 串口桥，ESP32-S3 的
> 原生 USB 引脚（GPIO19/20）被板载温湿度传感器的 I²C 占用了，所以传图走 Wi-Fi。
